# 🚀 稽影 (Jiying) 5 分钟上手指南

> 从零到跑通第一个 AI 协作任务

---

## 第一步：安装（30 秒）

```bash
git clone https://github.com/Vane1981-2011/jiying.git
cd jiying
npm install
npm run dev
```

打开 `http://localhost:5173`，你会看到稽影工作台。

---

## 第二步：配置 API Key（30 秒）

点击左侧 **⚙️ 设置** → 输入你的 **DeepSeek API Key**。

> 没有 Key？去 [platform.deepseek.com](https://platform.deepseek.com) 免费注册，新用户送额度。

---

## 第三步：输入第一个意图（1 分钟）

回到 **🔧 工坊** 页面，在输入框里试试这些：

| 意图示例 | Agent 会做什么 |
|:-----|:-----|
| *"帮我分析一下特斯拉 Q2 财报的核心风险"* | Planner 拆解 → Researcher 搜集 → Creator 撰写 → Reviewer 打分 |
| *"对比 React 和 Vue 在当前项目中的适用性"* | 技术调研 + 多维度对比表 + 推荐理由 |
| *"写一份 AI Agent 安全领域的研究综述"* | 文献收集 + 结构化综述 + 参考文献标注 |

点击 **▶ 开始**，观察 6 个 Agent 接力协作。

---

## 第四步：理解发生了什么（2 分钟）

```
你的意图
   │
   ├── Planner    拆解为子任务，输出 JSON 执行计划
   ├── Researcher 搜集信息，标注来源
   ├── Creator    生成内容，剥离假设
   ├── Reviewer   1-5 分评分，指出问题
   │
   ├── ⚖️ 宪法系统  三条规则自动过滤（尊严·自主·追问）
   ├── 🛡️ 质量门禁  7 项预检（覆盖率、占位符、去重…）
   └── 📤 导出     一键 Markdown 下载
```

### 你会看到

- **右侧面板**：任务上下文、宪法状态、审计日志
- **中间区域**：每个 Agent 的输出卡片，可展开查看详情
- **底部**：质量评分和改进建议

---

## 第五步：理解三条宪法

稽影不只是"帮你干活"，它**追问你**：

| 宪法 | 来源 | 做什么 | 效果 |
|:-----|:-----|:-----|:-----|
| 🛡️ 尊严 | 康德 | AI 必须声明身份 | 未声明 → **自动阻断** |
| 🔓 自主 | 马尔库塞 | 必须提供 ≥2 个替代方案 | 不足 → 自动追加 |
| 🔍 追问 | 海德格尔 | 必须声明前提假设 | 缺失 → 警告+补充 |

> 这不是一个"更聪明的 AI Wrapper"——这是一个**有价值观底线的知识工作台**。

## 常见问题

**Q: 为什么需要我自己的 API Key？**
A: 所有 AI 调用从你的浏览器直连 DeepSeek，零数据经过任何服务器。你的数据你做主。

**Q: 能接其他模型吗？**
A: 能。设置页面支持切换模型。任何兼容 OpenAI API 格式的服务都可以。

**Q: 任务中断了怎么办？**
A: 刷新页面即可恢复。每个 Agent 步骤完成后立即持久化，断点续传。
